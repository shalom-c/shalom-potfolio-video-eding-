# Shalom Taki Sunday — Next.js Portfolio

This is the App Router version of the original HTML/CSS/JavaScript portfolio. The original files in the parent folder are unchanged.

## Run locally

Run these commands from the repository root:

```sh
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content to update

- Update the contact address and mailto links in `components/Navbar.js`, `components/Hero.js`, and `components/Contact.js` if needed.
- Update projects and video IDs in `data/projects.js`.
- Project thumbnails and the hero image currently load from YouTube and Unsplash. No local assets need to be copied; add any new remote image hosts to `next.config.js`.
